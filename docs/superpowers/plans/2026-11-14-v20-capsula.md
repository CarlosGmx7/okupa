# v20 Cápsula del tiempo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Cartas de uno al otro que solo se pueden leer desde una fecha, con aviso ese día a las 8:00.

**Architecture:** Metadatos públicos en `parejas/{c}/capsulas/{id}` y texto sellado en `capsulas/{id}/contenido/texto`, protegido por reglas que comparan `request.time` con `abreMs`. Lógica pura en `js/modulos/capsula/logica.js` (la usa también el servidor, en el paso de fechas de las 8:00).

**Tech Stack:** igual que v19 (módulos ES sin compilar, Firestore + emulador, Node 20 + firebase-admin, `pruebas/corredor.js`).

**Spec:** `docs/superpowers/specs/2026-11-14-v20-capsula-design.md`

## Global Constraints
- Español colombiano con tuteo; DOM con `el()` (nunca `append`/`replaceChildren` nativos con `null` o listas: envolver en `el('div', {}, …)`); letra en rem; no usar `--acento` para el tema.
- Id de carta `^c-[a-z0-9]{4,30}$`. Metadatos exactos `{ de, abreEl, abreMs, creadaMs }`; texto exacto `{ texto }` de 1 a 2.000 caracteres (tras `trim`).
- `abreEl` 'YYYY-MM-DD' entre mañana y hoy + 10 años (3.652 días) según el celular; `abreMs` = medianoche local de `abreEl`.
- Máximo 50 cartas por pareja (app). Sin editar tras enviar.
- Aviso: solo a quien no la escribió (`de != lugar`), el día `abreEl == hoy` (fecha local de su celular), texto `Hoy puedes abrir la carta de ${nombre} 💌` (sin nombre: `de tu pareja`).
- Copia local `okupa:capsulas` = `{ codigo, cartas }` (solo metadatos, nunca textos); ignorada si el `codigo` no es el de la pareja actual; fuera de la copia de seguridad.
- Caché `okupa-v20`; archivos nuevos a `PRECACHE` y `ESPERADOS`; pruebas nuevas a `pruebas.html`. Reglas: Carlos las pega antes de publicar. Sin push.
- PowerShell (bash falla). Probar en 127.0.0.1 con el service worker desregistrado.

## Review Focus
1. Leer el texto de una carta cerrada por la base de datos (no por la pantalla) debe fallar; abierta, funcionar → Task 2.
2. Carta creada con fecha pasada o a más de 10 años, o con `de` ajeno → rechazada por reglas → Task 2.
3. Aviso al autor, aviso repetido o día equivocado → Task 1 y Task 3.
4. «Borrar todo» deja textos → Task 4.
5. Pantalla de una carta que aún no abre no muestra «null» ni el texto; carta sin texto (falló la segunda escritura) muestra «Esta carta llegó vacía» → Task 5.

### Task 1: Lógica pura
**Files:** Create `js/modulos/capsula/logica.js`, `js/modulos/capsula/package.json` (`{ "type": "module" }`). Test `pruebas/capsula-logica.prueba.js` (a `pruebas.html`).
**Interfaces (Produces):**
- `type Carta = { id, de: 'a'|'b', abreEl: 'YYYY-MM-DD', abreMs: number, creadaMs: number }`
- `MAX_CARTAS = 50`, `MAX_TEXTO = 2000`, `MAX_DIAS = 3652`
- `diasHasta(abreEl, hoy) -> number` (0 = hoy, negativo = ya pasó; aritmética UTC sobre texto)
- `estaAbierta(carta, hoy) -> boolean` (`abreEl <= hoy`)
- `avisosCapsulas(cartas, hoy, lugar, nombres) -> string[]`
- `unirAvisos(base: {titulo,texto}|null, extras: string[]) -> { titulo, texto, ruta } | null` — sin extras: base con `ruta '#/fechas'` (o null); con extras: `titulo = extras[0]`, `texto` = resto de extras + (base ? [base.titulo] : []) unidos con ` · `, o `'Entra a leerla.'` si queda vacío; `ruta '#/capsula'`.
- `detalleInicio(cartas, lugar, hoy) -> string`: si hay alguna del otro con `abreEl == hoy` → `'Tienes una carta para abrir'`; si no, la próxima cerrada del otro → `'Próxima carta en N días'` (`'Próxima carta mañana'` si 1); si no, `'Escríbanse una carta'`.
- [ ] Pruebas (que fallen primero): `avisosCapsulas` solo al que no la escribió y solo `abreEl == hoy`; nombre faltante → `de tu pareja`; `unirAvisos(null, [])` = null; `unirAvisos({titulo:'Hoy es el cumpleaños de Yuli 🎂', texto:'Entra a ver sus fechas.'}, ['Hoy puedes abrir la carta de Carlos 💌'])` = `{ titulo: 'Hoy puedes abrir la carta de Carlos 💌', texto: 'Hoy es el cumpleaños de Yuli 🎂', ruta: '#/capsula' }`; `unirAvisos({titulo:'X',texto:'Y'}, [])` = `{ titulo:'X', texto:'Y', ruta:'#/fechas' }`; `diasHasta('2027-01-01','2026-12-31')` = 1; `detalleInicio` en sus tres casos.
